## Gotchas hit (for the record)

1. **Dirty git tree hides untracked files** — `nix eval` on this flake with
   untracked new host dirs silently evaluated a config without them
   (stateVersion came from the common default, everything else missing).
   `git add -A` before evaluating new hosts.
2. **Two `${namespace}.` top-level attrs in one host file are illegal** (Nix
   dynamic-attribute conflict) — merge into one `${namespace} = { ... }`.
3. hatch01's module resolves `inputs.nixos-hardware` through the *host*
   flake's `_module.args.inputs` — i.e. OUR pin. Keep it fresh.
